# ☕ Bright Coffee Shop - Sales Analysis

## 📊 Project Overview
The Bright Coffee Shop Sales Analysis project focuses on analyzing daily transactional sales data to generate actionable business insights.

Bright Coffee Shop has appointed a new CEO whose objective is to increase company revenue and improve product performance. As a Junior Data Analyst, the goal of this project is to analyze historical sales data and present meaningful findings that can support business decision-making.

## 🎯 Project Objectives

The analysis aims to answer the following key business questions:

- Which products generate the most revenue?
- What time of day does the coffee shop perform best?
- What are the sales trends across products and time intervals?
- Which products and categories are performing well or poorly?
- What recommendations can improve overall sales performance?
